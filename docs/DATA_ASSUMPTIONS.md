## 3. 行为模型（决定数据是否自洽）

每个会员有三个**潜变量**：`propensity`（购买倾向）、`price_sens`（价格敏感）、`loyalty`（忠诚度）。
它们决定购买节奏与活动响应，**但绝不写入任何数据表**——这是刻意的防泄漏设计，模型只能从可观测字段学习。

单次购买概率：

```
p = (0.42 + 0.40 × propensity) × exp(-idle_days / 470) × seasonal
```

- `idle_days`：距上次购买的静默天数，衰减体现"越久不买越难唤醒"
- `seasonal`：大促月 ×1.22
- 活动 treated 追加：`+ 0.38 × (1 − 0.55 × price_sens)`，即价格不敏感者响应更强（异质性效应）

## 4. 活动与增量效应

- 8 个活动，每个从目标人群中随机抽 1,200 人，50/50 分为 treated / control
- 目标规则只用**可观测字段**（会员等级、注册时间），不使用潜变量
- treatment 效应注入购买过程，因此 `campaign_assignments.converted` 与真实订单一致，可直接计算 Qini / AUUC
- 同一会员可进入时间窗不重叠的多个活动；同一活动内不会同时是 treated 和 control

实测的整体转化率（2026-10-21 生成）：

| 组 | 平均转化率 |
|---|---|
| treated | 10.3% |
| control | 7.4% |

个别活动出现接近 0 甚至负向的波动（如 C2025S1、C2026S2），这是小样本噪声，**刻意保留**——真实实验就是这样，用它来检验评测框架能否区分"真效应"与"波动"。

## 5. 已知偏差（诚实声明）

1. 会员注册增长是线性的，真实业务可能有爆发式拉新。
2. 没有模拟"尺码缺货""物流延迟"等供给侧约束。
3. 活动只发券，没有模拟短信/企微/导购一对一等其他触达方式。
4. 商品系列名为虚构（Aurora / CloudNine / Luna / Iris / Meadow / Ember / Drift / Sculpt / Tide），不对应任何真实品牌或货号。
5. 价格、成本、退货率为量级假设，**不可用于任何真实经营决策**。
